# MoonPress

MoonPress 可以把 Markdown 文档生成静态文档站，适合 MoonBit 开源库、教程和项目展示页。

## 为什么需要它

MoonBit 包作者需要一种轻量方式来发布教程、示例、API 说明和项目文档，并尽量留在 MoonBit 生态内部完成构建流程。
