# Markdown 语法参考

MoonPress 渲染一个实用的 CommonMark 子集，下列语法均有测试覆盖。

## 标题

支持 `#` 到 `######` 六级标题。每个标题会自动生成 `id` 和锚点链接，例如 `## 构建命令` 可通过 `#构建命令` 定位。

## 行内格式

- `**粗体**` 渲染为 **粗体**。
- `*斜体*` 渲染为 *斜体*。
- `` `行内代码` `` 渲染为 `行内代码`。
- `~~删除线~~` 渲染为 ~~删除线~~。
- `\*转义\*` 渲染为字面星号。

单词内部的下划线不会被解析，因此 `snake_case_name` 保持原样。

## 链接与图片

`[文字](/目标)` 生成链接。指向 `http://` 或 `https://` 的外部链接会自动添加 `rel="noopener noreferrer"` 并在新标签页打开。

`![替代文字](/assets/logo.png)` 生成带 `loading="lazy"` 的图片。

引用式链接可以让正文远离长 URL：正文写 `[文字][id]`，在文档任意位置单独一行定义 `[id]: https://example.com`。尖括号可以自动链接网址和邮箱：`<https://moonbitlang.com>`、`<hello@example.com>`。

## 列表

无序列表支持 `-`、`*`、`+` 标记，有序列表使用 `1.` 形式。缩进两个空格即可嵌套：

```markdown
- 外层条目
  - 嵌套条目
1. 第一项
2. 第二项
```

任务列表会渲染为复选框：

```markdown
- [x] 已完成
- [ ] 计划中
```

## 引用

```markdown
> 引用内容支持 **行内格式**。
```

## 表格

```markdown
| 名称 | 数值 |
|:-----|-----:|
| 左对齐 |    1 |
```

`:---` 表示左对齐，`---:` 表示右对齐，`:---:` 表示居中。

## 代码块

围栏代码块可以标注语言，语言会作为 `language-*` 类写入 `<code>` 元素。MoonBit、Rust、JavaScript、TypeScript、JSON、Bash、Python、TOML、YAML 会在构建期完成语法高亮，每个代码块带复制按钮，`title="..."` 属性可以添加标题：

````markdown
```moonbit title="hello.mbt"
let greeting = "hello"
```
````

## 脚注

正文写 `一个结论。[^1]`，再定义 `[^1]: 支撑说明。` —— 脚注会汇总到页面末尾并带回跳链接。

## 分隔线

由三个及以上 `-`、`*` 或 `_` 组成的行会渲染为水平分隔线。

## 转义

所有正文、属性值和 URL 都会经过 HTML 转义，因此文档内容无法向生成页面注入标签。
